# Notes

Short version for the next person, or the next agent. The long record is `CHANGES.md`.

**Install with `install.sh`.** `omarchy theme install` sees the `.git` folder and throws away `hyprland.lua`. The script copies the theme without that folder, so the lua stays.

**Do not retune the glitch.** `shader/cp2077.frag` is the look. Quiet windows are `8.0` (always) and `12.5` (30%). Idle split stays tiny so text stays solid. Hits are uneven on purpose.

**A still screen freezes a hit unless vfr is off.** While the shader is on, `debug:damage_tracking = 0` and `debug:vfr = false`. Damage tracking off is what redraws. Variable frame rate still skips the next frame when nothing else moves, and the last tear stays up. Off restores shader `""`, damage tracking `2`, and `vfr true`. The flag file `~/.local/state/omarchy/cp2077-glitch-off` means off. `Super+Shift+Alt+G` owns that flag. Do not add a 60 fps animation for the time the glitch is off.

**Battery.** The redraw is the cost. On a ROG Flow Z13 GZ301ZE it was about 1 W extra at 120 Hz on AC, and about 0.5–1 W at 60 Hz on battery, roughly 1–2% of a capped charge per hour. The key turns it off. The frame lines step every 1100 ms. That paint is not measurable on top of the shader, so leave them moving.

**Walls.** Shipped pictures: 1 and 6 NET, 2 and 7 ICE, 3 and 8 BD, 4 and 9 DOC, 5 and 10 DECK. If `~/.local/share/omarchy/cyberpunk-wallpapers` exists and the file for that desk is there, `cp2077-walls` uses it instead. The names, in order, are `cover-art.jpg`, `love-or-burn.jpg`, `night-city.png`, `male-v.jpg`, `female-v.png`, `corporate-plaza.png`, `downtown.png`, `kabuki.png`, `japantown.png`, `dogtown.png`, `heywood.png`, `santo-domingo.png`, `pacifica.png`, `badlands.png`, `north-oak.png`, `northside.png`, `arasaka-waterfront.png`. A missing file falls back to the theme picture for that desk. Do not put those images in this repo.

**Keyboard.** `cp2077-keys` flickers brightness on ASUS, except the ROG Flow Z13 GZ301ZE, which cycles live Aura color through yellow `FCEE0A`, cyan `00F0FF`, red `FE1038`, and neon green `57 255 20`. That keyboard is one zone. A sweep is the whole board, not a row. Other models: `KEYBOARD.md`. Never save color to flash inside the loop. `cmd` stays `0`. Name the model only. Do not record a serial, a UUID, a hostname, a home directory, a MAC, a machine id, or an Aura object path. Interface numbers on the bus are not part of the model.

**Frames.** Hyprland draws one continuous border and one chamfer. The visible frame is the click-through layer from `plugin/nightcity.frame` (id `nightcity.frame`, namespace `nightcity-frame`). `border_size` is 0, shadow is off, `gaps_in` is 2, `gaps_out` is 3, so the wallpaper in the gap does not read as a thick frame. Each edge is two runs. The gap is about 6–14 px, capped at 18% of the span, and the two halves step inward by 1 px. The focused window is the one that glows: yellow `#FCEE0A`, one halo at `lineWidth + 7` and alpha 0.22, and a short `#00F0FF` tick. A wider glow stack reads as a second border. Idle windows are one thinner stroke at 42% and they do not glow. Hyprland client `at` and `size` are already logical pixels, the same space as the layer. Do not divide by `monitor.scale`. Dividing paints the frame inside the window. Inset 3 px. Skip fullscreen mode 2 or more, hidden, unmapped, and any window with less than 48 px still on the monitor. Geometry polls every 160 ms and skips a repaint when the list is unchanged. The dislocation steps every 1100 ms, and only when shell animations are on. `keepLoaded` is true, so a QML edit applies after `omarchy restart shell`. Do not enable two `*.frame` plugins. `install.sh` will not add `nightcity.frame` when one is already listed.

**Lock.** `plugin/nightcity.lock` is the view and the strings, not the auth service. `install.sh` copies `/usr/share/omarchy/shell/plugins/lock` to `~/.config/omarchy/plugins/nightcity.lock`, overlays `LockView.qml`, `i18n/en.json`, and `manifest.json`, then adds id `nightcity.lock`, puts `omarchy.lock` in `disabledPlugins`, and lists the clone in `cloneSourceRestores`. It skips that whole step when some other `*.lock` plugin is already enabled. Two lock handlers fight, and the first one wins. A bad lock file can block unlocking. After a change, `omarchy restart shell`, then preview with `omarchy-shell lock preview` and leave with `hidePreview`. Do not lock the session to test. The page, the password plate, and the fingerprint plate stay a 1 px broken stroke. No halo. Seeds are 4, 11, and 19. Error turns the password plate `#FE1038` and the tick yellow. The page also draws 1 px cyan corner marks, header rules, and a footer with two diamonds. Yellow rules vanish on the yellow cover, so those marks stay cyan. The words are NIGHT CITY, SEALED, ACCESS, and TOUCH.

**Polkit.** `plugin/nightcity.polkit` is the same kind of clone of `/usr/share/omarchy/shell/plugins/polkit`. Password prompts stay the wide field. A fingerprint prompt is the 1 px plate, seed 19, caption TOUCH, and it does not glow. `install.sh` skips the clone when another `*.polkit` plugin is already enabled, and it will not remove that plugin. When it does install, it disables `omarchy.polkit` and records `nightcity.polkit` in `cloneSourceRestores`. Two agents must not both be enabled.

**Screensaver.** `bin/omarchy-screensaver` is a breach protocol: title BREACH PROTOCOL, a 6 by 5 code grid, one daemon sequence at a time, and a RAM / ICE / uplink column. It is not a flatline and not a character-cell picture. `bin/cp2077-sixel.c` encodes it. ImageMagick's sixel quantizer drops the yellow, so the script does not use that coder. The header is `ESC P 0 ; 2 ; 0 q`. P2 = 2 paints black. `install.sh` compiles the encoder with `gcc -O2` next to the script and does not commit the binary. The script must stay executable, or Hyprland falls through to the logo saver. Any key, or leaving the screensaver window, exits. It hides the Hyprland cursor on start and sets `cursor:invisible` back to false on the way out. Preview with `omarchy-launch-screensaver force`. Do not `pkill -f` the script path. Do not change the idle times in `shell.json` from this theme.

**60 Hz** is a choice. See `extras/monitors-60hz.lua`. Do not force `eDP-2` on every machine. `install.sh` does not install that snippet.

**Bar widget** id is `nightcity.workspaces`. The QML `moduleName` stays `omarchy.workspaces`.

**Menu names stay stock.** A label-only override of `apps` clears `provider`, and the Apps list opens empty. `install.sh` still replaces `omarchy-menu.jsonc` after saving `omarchy-menu.jsonc.nightcity-bak` once. Do not invent a new Apps label.

**Re-run.** Marked blocks in `looknfeel.lua`, `hyprland.lua`, `bindings.lua`, and `autostart.lua` are replaced. The rest of those files stays. Idle timeouts stay. An existing `*.frame`, `*.lock`, or `*.polkit` plugin id stays. The theme directory, the user bin scripts, the frame plugin, and the menu extension are copied again. `gcc` builds `cp2077-sixel` into `~/.config/omarchy/bin` on each run.

**Theme lua versus look.** `theme/hyprland.lua` sets the same border and gaps. The user's `looknfeel.lua` loads later and is the one that also owns the shader. The second `hl.config` in the Night City block must not set `screen_shader` or `debug`.
